Яндекс.Карты
yandex_get_all_stops.py`** — Собирает «сырой» список ID всех остановок с карты (через браузер).
clean_stops.py`** — Очищает собранный список от мусора (парковок, вокзалов), оставляя только остановки.
yandex_async_collector.py`** — Быстрый сбор расписания со всех остановок сразу (без браузера, напрямую через API).
yandex_schedule_parser.py`** — Сбор расписания одной выбранной остановки (через браузер).
spider_stops.py`** — Альтернативный поиск остановок (без браузера, шагает по маршрутам через API).

Портал its03.ru
its03_collector.py`** — Сбор прогнозов прибытия в реальном времени с портала its03.ru (через браузер).
its03_spider_stops.py`** — Сбор списка остановок через API its03.ru.

🚀 С чего начать (сбор расписания Яндекса)
1. Запустите `yandex_get_all_stops.py`, чтобы собрать ID остановок.
2. Запустите `clean_stops.py`, чтобы отфильтровать лишнее.
3. Вставьте полученные ID в `yandex_async_collector.py` и запустите его для получения Excel-файла с расписанием.

**Структура таблицы:**
* `Дата` — дата замера
* `Время_замера` — точное время замера
* `Остановка` — название остановки (задается в настройках скрипта)
* `Направление` — в какую сторону едет транспорт (задается в настройках)
* `Маршрут` — номер автобуса
* `Мин_до_прибытия` — целые минуты
* `Сек_до_прибытия` — точное время в секундах
* `Примерное_время_прибытия` — расчетное время (ЧЧ:ММ), во сколько автобус будет на остановке
* `Борт_ТС` — идентификатор конкретного автобуса на линии
